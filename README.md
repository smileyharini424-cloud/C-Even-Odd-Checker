# C Even Odd Checker

## Explanation

This program checks whether a given integer is even or odd.

It uses the modulus operator to determine whether the number is completely divisible by 2.

## Problem Statement

Write a C program to read an integer and determine whether it is even or odd.

## Features

- Accepts an integer
- Checks divisibility by 2
- Identifies even numbers
- Identifies odd numbers
- Uses if else condition

## How It Works

The program accepts an integer from the user.

The modulus operator (%) calculates the remainder after dividing the number by 2.

If the remainder is 0 the number is even.

Otherwise the number is odd.

## Sample Output

24 is an even number.
